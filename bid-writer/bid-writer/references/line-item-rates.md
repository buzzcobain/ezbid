**Inflation:** 1.0527 (April 2026 base to January 2027 start). Later starts: multiply all rates by (actual_inflation / 1.0527).
**PM fee:** £65.00 per unit x 1.0527 = £68.43 per unit (total beds + total KLDs combined)
**MCD discount:** 2.5% applied to the sub-total including PM fee

---

## How to generate a complete BOQ

For each project with a confirmed room schedule:

1. For each line item: **Rate (£)** x **qty/room** x **room count** = item sub-total
2. Sum items into four categories: **Bedrooms** | **Kitchens** | **Appliances** | **Loose Goods**
3. Add **PM fee**: £68.43 x (total beds + total KLDs)
4. **Sub-total** = all categories + PM fee
5. **MCD discount** = sub-total x 0.025
6. **Grand total = sub-total - MCD discount**

**Column key:** Rate(£) = verified unit rate from Flag22167 | C=Cluster | S=Studio | P=Premier | A=Studio ACC | K4-K9=KLD size
**qty/room = how many of this item per room or KLD of that type** (0 = blank cell = not applicable)

For starts after Jan-27: multiply all rates by (inflation_to_start / 1.0527)
