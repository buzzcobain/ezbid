# UK Planning Use Classes — Reference

*Relevant to PBSA and co-living classification. Updated for the Use Classes Order 2020 changes.*

---

## C4 — Houses in Multiple Occupation (small HMOs)

- 3–6 unrelated occupants sharing facilities
- Applies to smaller HMOs; does NOT require planning permission to change from C3 (dwellinghouse)
  in most cases (permitted development)
- **Rarely applies to purpose-built PBSA** — most PBSA is too large for C4 and falls into
  Sui Generis

---

## Sui Generis — Large HMOs and PBSA

- More than 6 unrelated occupants = Sui Generis (not a use class, requires specific permission)
- **Most PBSA falls here** — student accommodation blocks, managed cluster schemes
- Also covers: hostels, boarding houses, some co-living schemes
- Key point: a Sui Generis application for "student accommodation" or "managed accommodation"
  is a strong PBSA/co-living signal

---

## C3 — Dwellinghouses

- Standard residential: houses, flats, apartments
- Build-to-rent (BTR) is typically C3 — conventional apartments rented by one household
- **C3 alone does not indicate co-living** — look for co-living language in the description

---

## C1 — Hotels and Hostels

- Some co-living and apart-hotel schemes are classed C1
- Watch for "apart-hotel", "serviced apartments" combined with co-living language

---

## Mixed use

- Some schemes combine Sui Generis residential (PBSA/co-living) with ground floor commercial
  (A1/A3/E class) — common in city centres
- The residential element is what matters for classification

---

## What to look for in the application description

| Phrase | Likely classification |
|---|---|
| "student accommodation" | PBSA |
| "purpose built student accommodation" | PBSA |
| "cluster flats" | PBSA (usually) |
| "student studios" | PBSA |
| "co-living" | Co-living |
| "shared living" | Co-living |
| "young professionals" | Co-living |
| "managed accommodation" | Could be either — read further |
| "build-to-rent" alone | BTR (conventional) — probably not relevant |
| "build-to-rent with shared amenities" | Possibly co-living — read further |
| "apart-hotel" | Probably not relevant |
| "key worker accommodation" | Possibly relevant — check scale and format |

---

## Note on changing definitions

The sector is evolving. "Co-living" is not a formal use class and developers sometimes use the
term loosely. Some schemes described as co-living are essentially large HMOs; others are more
like premium BTR with enhanced communal facilities. Use the presence of:
- Dedicated communal lounges, co-working spaces, gyms
- All-inclusive rents
- Operator involvement
- Short or flexible tenancy terms

...as indicators of genuine co-living intent, regardless of how the application describes itself.
